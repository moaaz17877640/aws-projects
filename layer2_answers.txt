The Database Subnet has no route to the Internet Gateway because it must remain isolated for security. 
Databases store sensitive application data, so they should not be directly accessible from the internet. 
Only the application layer should communicate with the database.






Security Groups are stateful and work at the instance level, while NACLs are stateless and work at the subnet level. 
Security Groups allow traffic rules only, but NACLs can allow and deny traffic.
